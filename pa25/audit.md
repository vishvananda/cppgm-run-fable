# PA25 Audit

## Audit Plan

Scope: commits `5af052dd9..af72152aa` (PA25 slice: hidden-EH regions, typeid/RTTI,
dynamic_cast, source throw/try/catch, by-copy/mutable captures, initializer_list,
braced/pack deduction, closure Itanium manglings, EH file split), audited against
`pa25/README.md`, `pa25/plan.md`, and the pa14–pa24 regression surface.

### Files to inspect

- `dev/src/lowering/lower_eh.cpp` (new, 683 lines — the "EH file split"): verify it
  is a self-contained module, not an implementation fragment used to dodge the
  1500-line source limit on `lower_member.cpp`; verify throw/try/catch lowering is
  real control flow, not templated output.
- `dev/src/lowering/lower_vtable.cpp` (+239): RTTI record family (class,
  fundamental, pointer type_info records); check records are derived from sema
  types, not from test-shaped strings; check on-demand emission (no eager PA24
  output perturbation).
- `dev/src/lowering/lower_member.cpp` (+435): unwind-region placement,
  closure-init lowering for by-copy captures; check for per-call quadratic scans.
- `dev/src/lowering/lower_expr.cpp`, `lower_function.{cpp,h}`: `$call__N`
  cross-region materialization, typeid/dynamic_cast expression lowering.
- `dev/src/lowering/lower_name.cpp`, `lower_name_template.cpp`,
  `lower_name_parts.h` (+340 total): Itanium closure manglings (`_ZZ…EUl…E_`,
  `_ZTI Z…`); check manglings come from structured name parts, not string surgery.
- `dev/src/sema/sem_cast.cpp` (+172): dynamic_cast/typeid sema; check acceptance
  is type-system-driven (polymorphic class checks), not source-shape-driven.
- `dev/src/sema/sem_lambda.cpp` (+137): by-copy/mutable/default captures; capture
  field layout stays sema-owned.
- `dev/src/sema/sem_lifetime.cpp` (+191): may-throw analysis and full-expression
  temporary regions; performance of the analysis (no repeated whole-tree
  rewalks per expression).
- `dev/src/sema/sem_convert.cpp`, `sem_auto.cpp`, `template_deduce.cpp`,
  `template_order.cpp`: initializer_list recognition/preference and braced/pack
  deduction; check `std::initializer_list` detection is by scope identity, not
  name-string matching at use sites.
- `dev/src/sema/sem_binder.{cpp,h}`, `sem_expr.{cpp,h}`: throw/try/catch binding;
  header growth (+49/+12) vs the "substantial implementation body" warnings.

### Performance risks to check

- Unwind-region/dispatch-block reuse keyed on armed-cleanup sets — verify not
  recomputed by scanning all locals per call site.
- RTTI global emission — verify deduped by key, no repeated whole-unit walks per
  typeid/dynamic_cast site.
- May-throw analysis — verify memoized per function/node, not re-derived per
  call expression.
- Mangling construction — check for repeated substring scans over growing
  strings.

### Ownership boundaries to check

- sema owns acceptance, capture layout, may-throw facts, RTTI keys; lowering
  consumes typed facts. Look for lowering re-deriving semantic facts from
  strings (stringly typed RTTI keys, name-based closure identification,
  downstream re-parsing of mangled names).
- Runtime interfaces must be declared externals only (`__cxa_*`,
  `__dynamic_cast`); no interpreter/trampoline/embedded-payload substitutes.

### File-audit issues to inspect

- 4 warnings: `lower_function.h`, `parser.h`, `sem_binder.h`, `sem_expr.h`
  carry substantial implementation bodies. `sem_binder.h` is 1182/1200 lines and
  `sem_binder.cpp` is 1484/1500 — check whether PA25 pushed implementation into
  headers to stay under source limits, and whether near-limit files
  (`sem_class.cpp` 1499, `template_deduce.cpp` 1484, `sem_lifetime.cpp` 1442,
  `lower_unit.cpp` 1433) hide cohesion problems.
- Verify `lower_eh.cpp` split is by responsibility (EH lowering) rather than an
  arbitrary line-count split.

### Cheating checks

- Grep dev/src for test fixture names, hardcoded `.ref` content, source-file
  name gates, environment sniffing.
- Verify no fallback success paths (silent success on unsupported constructs
  that should EXIT_FAILURE, or vice versa).
- Verify LowIR is generated from the lowered program, not copied payloads.

## Findings

### Cheating / substitute-artifact checks — clean

- No test-name, fixture-name, or source-file gates anywhere in `dev/src`
  (grep sweep for test identifiers, `getenv`, `.ref` references; the only
  `getenv` uses are the shared `test_runner.cpp` harness).
- No comparator, script, or fixture changes in the PA25 commit range —
  the checked-in oracle is untouched. `.my`/`.check` files under
  `pa25/tests/` are gitignored dev-loop outputs.
- LowIR is generated by real lowering: throw/try/catch build genuine
  control flow (`lower_eh.cpp`), RTTI records derive from the type system
  keyed by Itanium encodings (`lower_vtable.cpp` `RttiTypeRef`), the
  initializer_list backing array stores each lowered element
  (`LowerInitializerListInit`). No embedded payloads, templated output, or
  interpreter/VM/trampoline substitutes. The only hardcoded symbol names
  are Itanium C++ ABI constants (`__cxa_*`, `__dynamic_cast`,
  `_ZTVN10__cxxabiv1*`).
- Runtime interfaces are declared externals only; no runtime code is
  generated beyond calls into them.
- End-to-end execution check: PA25 LowIR through the reference PA28
  `lowir2native` runs correctly for the non-EH slice (capturing lambda
  returns 7; sibling-lambda program returns 3; named-list copy program
  returns 30). EH/RTTI/dynamic_cast programs are rejected by
  `lowir2native` (`MI_LOAD_EXCEPTION_SELECTOR requires host EH-enabled
  function`, unresolved `__dynamic_cast`/`_ZTVN10__cxxabiv1*`) — expected:
  `pa28/README.md` explicitly defers "the private exception/runtime ABI
  path" to later assignments, and the checked-in `.ref` files have the
  identical shape.
- Negative tests are real acceptance checks: the three `-bad` typeid tests
  fail through `StdTypeInfoEntity`'s scope-based lookup (a global-scope
  `class type_info` is correctly rejected), not name-shape matching.

### Bugs found and fixed

1. **Closure discriminator keyed on the wrong scope** (`sem_lambda.cpp`).
   The Itanium `<lambda-sig>` discriminator counted prior same-signature
   lambdas per *immediate lexical scope*; two same-signature lambdas in
   sibling blocks of one function both mangled `_ZZ4main...UlvE_clEv` with
   `binding=weak` — duplicate ABI symbols for distinct bodies (weak-symbol
   dedup would fold different code). Fixed by keying the count on the
   enclosing function body (the mangled local-name prefix context,
   mirroring `LocalEntityFunctionScope`); sibling-block lambdas now emit
   `UlvE_` / `UlvE0_`, matching g++.
2. **`main` local-name prefix carried a signature** (`lower_name.cpp`).
   Closure members in `main` mangled `_ZZ4mainvENK...` where g++ and the
   checked-in refs spell `_ZZ4mainENK...` (main is unmangled, so its
   local-name prefix has no bare-function-type). Fixed with an explicit
   `::main` case in `MangleEnclosingFunctionEncoding`.
3. **`"__this"` name-string gates in lowering produced wrong code**
   (`lower_member.cpp`). `LowerClosureInit` identified the captured-this
   field by `field.name == "__this"` and `MemberAddress` identified
   captured-this member access by node name. A program capturing a local
   named `__this` by copy compiled silently and stored the variable's
   *address* instead of its value (probe returned 172 instead of 42).
   Fixed with typed facts: `ClassField::captured_this` (set by
   `EnsureThisField`) and `SemNode::captured_this` (set by
   `ThisValueNode`); lowering now consumes sema-owned identification.
   Probe returns 42.
4. **Missing const on by-copy captures in non-mutable lambdas**
   (`sem_lambda.cpp`). `[n]() { n = 5; }` compiled and mutated the
   closure field; 5.1.2p16 makes non-mutable by-copy members const.
   `TryCaptureUse` now const-qualifies the read type when the capture is
   by-copy and the lambda is not `mutable`; the assignment is rejected
   through the existing modifiable-lvalue check.
5. **Hardcoded `__size` field offset** (`lower_member.cpp`).
   `LowerInitializerListInit` emitted `index i8 dest, 8` for the size
   field instead of consuming sema's layout fact. Now validates the
   two-field record shape and uses `cls->fields[1].offset`.
6. **Duplicated std::type_info recognition in lowering**
   (`lower_eh.cpp`). `IsTypeInfoComparison` re-identified std::type_info
   by scope-name strings (`"type_info"`/`"std"`), a second stringly
   recognition point beside sema's `StdTypeInfoEntity`. Sema now records
   the recognized entity on the unit (`SemUnit::std_type_info`, populated
   by `FindStdTypeInfo` at end of binding and on first typeid use);
   lowering compares pointer identity via `LowerProgram::IsStdTypeInfo`.
7. **Scope-unchecked initializer_list match in braced deduction**
   (`template_deduce.cpp`). The 14.8.2.1p1 branch matched any template
   named `initializer_list` regardless of declaring scope, so a user's
   `ns::initializer_list` would participate in element-wise deduction.
   Extracted the scope-verified check into `IsStdInitializerListTemplate`
   (shared with `IsStdInitializerList`) and used it there.
8. **Builtin initializer_list record had no implicit special members**
   (`sem_template.cpp`). Copying a named list (`sum(v)`,
   `std::initializer_list<int> w = v;`) failed with "no matching
   constructor" even though the record is a trivially copyable 16-byte
   class. `BuildBuiltinInitializerList` now runs
   `DeclareImplicitSpecialMembers`; the named-list copy probe compiles and
   executes correctly (exit 30) through the reference native backend.

### Reviewed and accepted (no action)

- **`lower_eh.cpp` split**: a cohesive module (source-level EH statements
  plus the typeid/dynamic_cast expression forms that share the EH runtime
  scaffolding), registered in `frontend_source_sets.mk`, fully inside the
  audited `dev/src` path. Not a line-count dodge.
- **Header warnings**: 3 of 4 pre-date PA25 (verified by running the
  audit at the base commit); `lower_function.h` newly crossed the
  heuristic's 180-`;`-line threshold, but its PA25 additions are member
  *declarations* and small context structs — no implementation moved to
  headers. The one inline addition (`EnsureSpecialCtorHost`, 8 lines) is
  a dispatch shim.
- **`BranchSpellsFnPointerAddress` fold**: pre-existing PA18 analysis
  (moved, not added, by the file split); out of this audit's blame range
  and already conservative (whole-program alias proof, cached per key).
- **`AdjustToBase(_, 1)` for captured-this member access**: emits an
  offset-0 `[projection=base_subobject]` no-op purely to match the
  pinned reference instruction shape; semantically inert, now keyed on
  the typed `captured_this` fact.
- **`EhObjGlobal` weak zero globals**: reference-presentation scaffolding
  pinned by the `.ref` oracle, documented in the plan.
- **Class-element initializer_lists**: the shipped contract tests
  (`200-braced-assignment-prefers-initializer-list`,
  `200-member-template-initializer-list-deduction`) require the
  trivially-destructible class-element subset to work, so the in-place
  construction path in `LowerInitializerListInit` stays. Elements with
  user destructors are README-declared UB (out-of-scope input), not a
  fallback success path. An experiment rejecting class elements broke
  both contract tests and was reverted.
- **`ClassifyTransferCtor` one-level user-dtor probe**: the visible-call
  vs raw-copy choice is presentation-only (both forms copy identical
  bytes for these types); the one-level probe matches every pinned ref
  shape, and no ref evidence exists for deeper nesting.
- **`CleanupSignature` per-region string key**: O(live cleanups) per
  region open, bounded by function size; required for the ref-pinned
  dispatch-block reuse. No whole-program or cross-function scans.

### Performance

- RTTI records, runtime declares, external vtable refs, and `__ehobj`
  globals are all deduped by map/set on first use; no repeated
  whole-unit walks per site.
- May-throw facts are sema-owned (`fn_unwind_no`, `NodeMayThrow`);
  `ScanArmsCleanups`/`SegmentContainsCall` are linear per full
  expression/segment.
- Mangling caches closure local names in the substitution table;
  object names compute once per emitted symbol.
- `Scope::bindings` moved from `vector` to `deque` for pointer
  stability across mid-analysis declarations — a correctness fix with
  bounded cost.
- The discriminator count is O(prior same-context lambdas) per lambda at
  bind time; bounded.
